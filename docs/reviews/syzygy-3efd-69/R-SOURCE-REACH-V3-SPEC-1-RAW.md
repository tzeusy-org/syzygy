### F3 — non-blocking — design.md:87 (D7): the active-content forecast names the wrong languages and forms

[Observed] `scanActiveContent` from `@syzygy/three-surface-poc-core` (scratch `ac.mjs`): `val m: Map<String, Int> = mapOf()` → `[]`; `if (a < b && c > d) {}` → `[]`; `case class A[T <: B](x: T)` → `[]`; `f <$> x` → `[]`; but `Future<void> main()`, `class Foo<T> {}`, `new ArrayList<String>()`, `List<Widget> …` → `html-tag`. Through the screen, `src/main/scala/Cmp.scala` holding `if (a < b)` and `build.gradle.kts` holding `Map<String, Int>` are both `admitted`.
So D7's "source in languages with angle-bracket generics or comparisons (Scala, Kotlin scripts, Dart, Groovy, OCaml, Haskell) … will often be excluded" overstates. Comparisons are not flagged. Scala's generics use square brackets. A Haskell operator such as `<$>` is not flagged. What is flagged is a single identifier in angle brackets (`<T>`, `<void>`, `<String>`), which is common in Kotlin, Dart, Groovy and Java-style code. The paragraph is labelled [Inferred], but a reader will take its examples as guidance.
Repair: name the actual trigger (an identifier directly inside `<…>`), list Kotlin, Dart and Groovy as the likely casualties, and drop Scala, OCaml, Haskell and "comparisons", or label them [Unknown].
