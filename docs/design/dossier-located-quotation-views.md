## Proposed requirement delta

[Inferred] Replace the raw-display sentence in REQ-polaris-generation-034 with the following contract. Every admitted quotation in an operator-agent claim block or inventory entry SHALL be located again at render in the verified pinned blob using the existing exact locator, including its line-range and contiguous-match checks. Syzygy SHALL retain the chosen substring of the blob's tracked normalised text from that same locator invocation and the corresponding original span. The reading view SHALL show the chosen substring as a quotation and disclose that syntax was normalised. The evidence view SHALL show the located original span byte for byte as escaped inert text. Both SHALL identify the same original byte range through one existing RFC7-10 anchor. Stored offsets, a second normalisation of the clipped original span, and the draft's text shall have no authority to supply either view.

[Inferred] Preserve the exact shape and meaning of existing local machine quotation rows. The original offset tuple and anchor still identify the corresponding raw evidence. The existing source-page route and read rules supply the original bytes when admitted. The normalized text is a presentation value and adds no machine body field or new source surface. Only the original quotation markup SHALL carry the byte-fidelity coordinates. A claimant's named source or quote string does not substitute for a re-located span. The existing source page, code-excerpt byte treatment in both views, and the provider golden remain governed by their current rules.

[Inferred] The existing exclusion and withheld clauses apply before the match and to its two outputs. A changed, unlocated, invalid, excluded or redacted-overlap source cannot furnish either view. Run the existing detector on the derived projection as well as the source input, so joining text during normalisation cannot admit a detector match. If the projection fails classification or screening, emit the existing bounded withheld/Unknown state for the quotation and no raw or normalised bytes for that quotation. Preserve the existing outside-the-quote source admission rule. [SEC-5](../../.syzygy/governance/doctrine/security.md#non-negotiable-rules)
