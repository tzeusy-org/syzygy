# Repositories the owner owns

The owner's list (security.md SEC-4, vision.md VIS-4 class 3). Syzygy writes
and pushes into a repository on this list without a per-repository consent;
a write or push into any other repository needs the owner's recorded consent
for that repository.

**Only the owner changes this list.** Adding a repository, removing one or
changing a row is an owner decision: it is recorded as the owner's words,
dated, in the commit that makes the change. An agent never edits this file,
not even to add a repository it believes the owner owns; a repository not
listed here counts as not owned.

Reading needs no entry here: any repository, public or private, may be read
and sent to a run's declared provider (SEC-2).
