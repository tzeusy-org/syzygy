# Consent refusal disclosure design

Project the single refused decision captured for the producing evaluation to
its human fact set and machine answer. The observed presence of a consent
artifact and its record state is distinct from the Unknown authorization of
the effect. Reuse the ordinary CAP1-REQ-046 explanation path, the existing
CAP1-REQ-011 refusal diagnostic and the producing evaluation identity so
the two channels cannot disagree about which refusal they explain. Use the
same safely evidenced effective artifact record state. Use Unknown for
that state if the capture cannot establish it, regardless of the refused
assertion's self-declared stamp.

| Captured state | Human fact set and machine answer |
| --- | --- |
| Exact identity and digest independently established for the refused artifact and admitted under SEC-5 | Same observed pair, exact evaluation, authorization Unknown, safe diagnostic and owner route |
| Pair missing, incomplete or independently unsubstantiated | Same evaluation and refusal, pair Unknown with missing-evidence and an applicable resolution route |
| Pair or its provenance in excluded material | Same evaluation and refusal, pair Unknown with excluded-content and an applicable safe resolution route |

A consent assertion may lie about its own identity and digest. A safe
metadata pair must name the particular artifact held in the producing
evaluation, from admitted evidence independent of those asserted fields.
A safe mismatch diagnostic identifies the failing check without echoing
unscreened values. Withheld values never enter either answer, route text or
any intermediate index. This projection consumes only the already captured
admitted metadata. It makes no new read, hash or screen of an excluded
artifact and grants no further authority.

The independent fixture ledger names the full population and places missing
and withheld provenance cases alongside the confirmed positive and
mismatched-assertion cases. Separately omit each channel's entry to
distinguish retained refusal from observed identity availability. Check the
accessible explanation using the existing keyboard route. Maintain the
CAP1-REQ-011 controls on refused dependent reads and the captured evaluation
immutability property.
