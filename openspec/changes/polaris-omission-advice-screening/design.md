# Omission advice report projection

[Inferred] The coverage comparator first computes matches, coverage totals, and the three ordered, distinct omission lists. The report projection applies the bound policy's combined path-or-text predicate, implemented by `secretPathOf`, to each identifier due to be emitted. A path-side secret match settles the decision. Otherwise the text-side detector tests the same identifier, including after a path-only denial. It adds one to the list's count for each matched identifier and emits every other list member in the order established by the comparator. The paired counter and visible length account for each list. One identifier can contribute to more than one list's counter.

The `compared` report exposes the three counts as `omissions.withheld`, including numeric zeros where appropriate. With `state: "unknown"`, the already-defined reason and note describe the unavailable comparison. The report encoder applies the withholding rule after the existing outcome and inventory comparison are determined. If a required classification is unavailable, the encoder returns the Unknown advice arm with the fixed reason `omission advice screening was unavailable`. Check's outcome and stored check record follow the rules for the completed comparison.
