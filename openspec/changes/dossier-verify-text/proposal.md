## Why

- [Observed] Syzygy verifies quotations and citations only inside a schema-valid draft: `deriveFindings` (`packages/polaris-dossier/src/check-derive.ts`) takes a draft's blocks and citations, and no command of `packages/polaris-dossier/src/cli.ts` takes free-form text (move R2's basis).
- [Inferred] So the dossier's main advantage, that each claim is anchored and each quotation is real, cannot be shown beside a plain answer, and a plain session's accuracy cannot be scored mechanically. R1's comparison protocol and R15's ask command both need that instrument.
- [Observed] First measurement with the implementation, over the 2026-11-21 pilot (`docs/evidence/syzygy-5dhm-23/verify-text-pilot-2026-11-22.json`): the plain synthesis names 128 file references, none with lines; the newest Redis dossier as text names 336, 180 with lines. [Inferred] All 180 line-bearing references resolve at the pinned revision: the record's reading says so, and its stored figures do not split reference states by lines.
