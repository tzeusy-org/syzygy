#### Scenario: Local run without retired records

- **WHEN** a controlled local clone, valid declarations and committed policy are supplied without consent, registry-act, drawer or provider-statement records
- **THEN** the run initializes and issues its brief without a terminal question or governance write, recording its full pin and declared provider
- **AND** governance paths in the clone do not add a statement gate

#### Scenario: Pinned objects and policy cannot drift

- **WHEN** a fixture's object bytes are altered after pinning, its policy binding changes, or its declared provider differs from the bound brief
- **THEN** the dependent step refuses with the violated predicate and no invalid content or stale verdict is admitted

#### Scenario: Conservative visibility preserves exclusions

- **WHEN** identical detector-matching fixtures are run as public, private and with no visibility declaration
- **THEN** public effective redaction equals its predecessor behavior and private/absent declarations exclude the whole body and suppress excluded/withheld identifiers and sizes
- **AND** no network or credential operation is made to establish visibility

#### Scenario: Legacy continuation is explicit

- **WHEN** a command receives a retained polaris-dossier-run/1 record
- **THEN** it explains the unsupported legacy continuation and how to start a new run, without modifying any original file or presenting old consent as current verification

#### Scenario: Disclosures name actual evidence

- **WHEN** a /2 fixture is checked, rendered and closed
- **THEN** both channels distinguish declared provider and stored pin history from checks rederived now, record unknown usage honestly, and claim no retired consent or statement was verified

#### Scenario: URL projection does not inherit a false local dispatch reason

- **WHEN** a URL-supervised /2 core still contains its compatibility operator-agent mode, three eligible classes and operator-started no-provider-dispatch reason
- **THEN** the validated URL overlay supplies the effective authoringMode, class declaration and local-supervisor/no-scheduler reason in appendix, machine narrative, close and Execution Record projection
- **AND** missing send/usage capture is Unknown, never zero, and an ordinary /2 without URL metadata retains its original operator-started meaning

#### Scenario: Raw-read disclosure across a rendered dossier

- **WHEN** an operator-agent dossier renders more than one page and has a declared provider
- **THEN** the run record and human appendix state that the authoring session read the raw clone unscreened and a secret in it may have reached that declared provider
- **AND** every rendered page's machine form carries that disclosure, including pages that show no author-written claims
- **AND** the wording states the risk without identifying a secret or claiming an actual secret transmission

#### Scenario: Raw-read disclosure when there is no site

- **WHEN** an operator-agent run is recorded and stops without rendering a page
- **THEN** the run record still carries the unscreened raw-clone and declared-provider risk disclosure
- **AND** if the run stopped before author handoff it records that the authoring session was not reached, and if handoff cannot be established it records Unknown, with neither case claiming that an actual read occurred
- **AND** a historical /2 with no companion preserves its bytes on inspection, and a mismatched run identity or provider in a required companion refuses a new site render

#### Scenario: Checked relay evidence does not stand for raw-read traffic

- **WHEN** a URL-supervised run has captured relay attempts and the session's own transmissions are uncaptured
- **THEN** the run discloses the separate capture population, keeps uncaptured transmission facts Unknown and carries the D11 disclosure
- **AND** a detector match or unclassifiable content in a captured relay request refuses that request under the same rules as before this amendment
