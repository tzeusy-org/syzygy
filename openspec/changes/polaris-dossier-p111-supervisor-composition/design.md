# P111 design

The attended view projects the existing supervisor rather than creating a second run. It reads the run and attempt identifiers, observed current step, original deadline, applicable limit and next allowed action. The normal `attach` action inspects that attempt and records verified view evidence. A change to run state uses its separate stop or resume action. A verified interval proves detach and reattach for the same run; unavailable evidence yields the named Unknown state. Stop and existing resume continue through their existing independent transitions. [Exact attended predecessor](../polaris-dossier-attended-supervisor-view/SEMANTIC-DELTA.md).

One ordinary wait, one eligible Author question and one unavailable wait use distinguishable plain-language states. The view tells the reader where the Author question is and retains the existing safe question action when the view is unavailable. Inputs and receipts remain in the existing bounded and separately authorized question gate. The candidate relies on the independent synthetic design-bar result for discoverability, focus, keyboard access and announcement. Actual tool support and actual launch evidence remain Unknown. [Design and transcript evidence](../polaris-dossier-one-command-run/ATTENDED-VIEW-DESIGN.md).

The candidate inherits exact role admission, fixed-source and artifact bindings, parent deadlines, no-observed-code execution, separate provider declarations, artifact screening and recorded absence of verified inventory completeness. The local raw-author disclosure follows D11 and A-51 and carries the existing stopped-before-reach semantics. An unavailable view or closed transport never stands in for a role proof or a substantive successful review. [Role composition](ROLE-COMPOSITION.md).
